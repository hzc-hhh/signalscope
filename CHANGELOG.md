# Changelog

All notable changes to SignalScope will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-05-31

### Added
- Initial project structure and package setup
- Core pipeline framework with model registry
- Radar preprocessing module: IQ-to-displacement, clutter removal, phase unwrapping, vital sign extraction
- PPG and ECG preprocessing stubs with multi-modal sync
- Deep model zoo: ResNet1D, Time-Series Transformer, SSL pretraining stub
- Classical signal processing baselines
- Evaluation metrics suite (regression, classification, statistical tests)
- Benchmark runner with leaderboard generation
- Interpretability module (signal attribution, medical mapping placeholder)
- CI/CD via GitHub Actions
- Full documentation skeleton with MkDocs
